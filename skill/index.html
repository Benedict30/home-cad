How to use it

  1. Download the ZIP with the button above. It's easiest on a computer.
  2. Add it to Claude. At claude.ai or in the desktop app, go to Customize › Skills, click +, then Create skill › Upload a skill. Choose the ZIP and switch it on. Skills need Code execution and file creation turned on in Settings › Capabilities.
  3. Send your floor plan. Start a new chat, attach a clear photo of your HDB floor plan, and send 3 lines about your home. Change the example to fit you:
    Plan my home. Floor plan attached. We are: couple, no kids, 1 Shih Tzu Coming up: more work from home Must-haves: a dog wash spot
